# Checklist ทดสอบมือสำหรับ refactor

ใช้กับส่วนที่ test อัตโนมัติยังไม่ครอบคลุม (ต้องใช้เบราว์เซอร์จริง) รัน `npm run dev` แล้วตรวจเฉพาะหมวดที่เฟสนั้นแตะ ตรวจหนึ่งรอบก่อนแก้เพื่อรู้ว่าของเดิมเป็นอย่างไร

## Markdown

- [ ] พิมพ์ใน Source แล้ว preview ตาม, สลับ Read & edit (WYSIWYG) กลับไปมาแล้วข้อความไม่เปลี่ยน
- [ ] Outline กระโดดถูกหัวข้อทั้งสองโหมด
- [ ] ลากเส้นแบ่ง source/preview, ดับเบิลคลิกคืน 50/50
- [ ] เปิดไฟล์จากดิสก์ แก้จากโปรแกรมอื่น แล้วกลับมา: ปุ่ม refresh แจ้งว่ามีการเปลี่ยน, ลบไฟล์แล้วมีคำเตือน
- [ ] ปิดแล้วเปิดหน้าใหม่: เอกสารและข้อความที่ยังไม่ save กลับมา
- [ ] Export HTML, Copy HTML, Print

## Text

- [ ] Alt+ลาก และ Alt+Shift+ลูกศร เลือกแบบคอลัมน์, พิมพ์ ลบ วาง ในคอลัมน์
- [ ] Find / Replace ไฮไลต์ตรงตำแหน่ง, Go to line
- [ ] Tab / Shift+Tab, ทำซ้ำบรรทัด, Ctrl+Z ย้อนได้
- [ ] Wrap เปิดปิด, เลขบรรทัดเลื่อนตรง
- [ ] เปิด CSV เป็นตาราง สลับกลับเป็นข้อความ
- [ ] เปิด 3 splits, ย้ายเอกสารข้าม split, สลับ split ด้วย shortcut

## PDF

- [ ] เปิดไฟล์, เลื่อนหน้า, zoom, fit width / fit page
- [ ] ใส่ข้อความ (รวมภาษาไทย), highlight, กรอบ, ปิดทับ, ปากกา แล้ว undo / redo
- [ ] หมุน ลบ ย้ายหน้า, แทรก PDF อีกไฟล์, thumbnail ตรงกับหน้า
- [ ] Save แล้วเปิดใหม่: ทุกอย่างอยู่ตำแหน่งเดิม, เมนู Export ใช้ได้

## Diff & Merge

- [ ] วางสองฝั่ง, เลือก M / A / M+A / ✕ ทั้งรายบรรทัดและทั้งบล็อก
- [ ] ย่อ/ขยายบรรทัดที่เหมือนกัน, ข้ามไปบล็อกถัดไป, สลับฝั่ง, save ผลลัพธ์

## ทั้งแอป (main.ts, i18n, CSS)

- [ ] ลากไฟล์มาวางแล้วเปิดใน tab ที่ถูก, รายการ Recent เปิดได้
- [ ] shortcut, command palette, ตัวแก้ shortcut
- [ ] สลับภาษา EN / TH, ธีม light / dark, focus mode
- [ ] จอกว้างไม่เกิน 760px
