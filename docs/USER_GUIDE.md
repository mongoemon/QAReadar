# คู่มือการใช้งาน QAReadar

QAReadar เป็นเครื่องมือบนเว็บสำหรับงาน QA มี 3 แท็บ:

| แท็บ | ใช้ทำอะไร |
| ---- | --------- |
| **Markdown** | เขียน / อ่าน / แก้เอกสาร Markdown เช่น test case, test plan, bug report |
| **JSON Path** | ดู JSON เป็น tree, หา path ของค่าที่ต้องการ, ค้นหา, แปลง CSV / YAML / JSON Lines เป็น JSON |
| **Locator** | วาง HTML ของหน้าเว็บแล้วคลิก element เพื่อได้ locator สำหรับ Playwright / Robot Framework / Selenium |

เปิดใช้ที่ **https://qareadar.pages.dev**

> 🔒 **ไฟล์ทั้งหมดอยู่ในเบราว์เซอร์ของคุณ** ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์ ใช้กับข้อมูลงานได้อย่างสบายใจ

บน macOS ใช้ `Cmd` แทน `Ctrl` ทุกคีย์ลัดในคู่มือนี้

## 2. เปิดและบันทึกไฟล์

### เปิดไฟล์
- กดปุ่ม 📂 หรือ `Ctrl+O`
- หรือ **ลากไฟล์มาวางที่ไหนก็ได้ในหน้า** (ลากหลายไฟล์พร้อมกันได้)

แอปจะเลือกแท็บให้ตามนามสกุล:

| นามสกุล | เปิดในแท็บ |
| ------- | ---------- |
| `.md` `.markdown` `.txt` | Markdown |
| `.json` | JSON Path |
| `.jsonl` `.ndjson` `.csv` `.yaml` `.yml` | JSON Path (แปลงเป็น JSON ให้) |
| `.html` `.htm` | Locator |

ไฟล์ที่ไม่ใช่ข้อความ (รูป, zip) จะขึ้นว่าไม่รองรับ (PDF เปิดในแท็บ PDF) และไฟล์ใหญ่เกิน **20 MB** จะไม่ถูกเปิด

### บันทึก
- **บันทึก** (`Ctrl+S`): เขียนทับไฟล์เดิม ถ้าเป็นเอกสารใหม่จะถามว่าจะเก็บที่ไหน
- **บันทึกเป็น…** (`Ctrl+Shift+S`): บันทึกเป็นไฟล์ใหม่เสมอ

### ไฟล์ล่าสุด
ปุ่ม 🕘 แสดงไฟล์ที่เปิดล่าสุด 10 ไฟล์ คลิกเพื่อเปิดอีกครั้ง

> ℹ️ การบันทึกทับไฟล์เดิมและรายการไฟล์ล่าสุดใช้ได้ใน **Chrome / Edge**
> ใน Firefox / Safari การบันทึกจะเป็นการดาวน์โหลดไฟล์ใหม่ และไม่มีรายการไฟล์ล่าสุด

## 3. แท็บ Markdown

### มุมมอง
- **Markdown (ค่าเริ่มต้น)**: ซ้ายเป็นโค้ด Markdown ขวาเป็นตัวอย่างที่ render แล้ว
  - **ลากเส้นแบ่งตรงกลาง** เพื่อขยายฝั่งใดฝั่งหนึ่ง (20–80%) ดับเบิลคลิกเส้นแบ่งหรือกดปุ่ม ⇔ เพื่อกลับเป็น 50/50
- **อ่านและแก้ไข / Read & edit** (ปุ่ม 📖): หน้าอ่านแบบสะอาด **พิมพ์แก้ได้ในหน้านั้นเลย** ไม่ต้องรู้ Markdown กดอีกครั้งเพื่อกลับไปมุมมอง source
- มุมขวาล่างของ editor มีปุ่ม **Markdown / WYSIWYG** สำหรับสลับแบบ editor ปกติ

### แถบเครื่องมือ

| ปุ่ม | ทำอะไร |
| ---- | ------ |
| 🔄 | โหลดไฟล์ใหม่จากดิสก์ (เมื่อไฟล์ถูกแก้จากโปรแกรมอื่น จะมี **จุดสี** ขึ้นที่ปุ่ม) |
| ☰ สารบัญ | แสดงหัวข้อทั้งหมด คลิกเพื่อกระโดดไปหัวข้อนั้น |
| 🔍 | ค้นหาและแทนที่ |
| 📖 อ่านและแก้ไข | สลับมุมมองอ่าน / source |
| A↓ / A↑ | ตัวอักษรเล็กลง / ใหญ่ขึ้น |
| ↔ | ความกว้างคอลัมน์ แคบ / ปกติ / กว้าง |

ขนาดตัวอักษร ความกว้าง และสัดส่วนเส้นแบ่ง **จำไว้ให้** ครั้งหน้าเปิดมาจะเหมือนเดิม

### หลายเอกสาร
- เปิดหลายไฟล์พร้อมกันได้ แต่ละไฟล์เป็นแท็บเล็กใต้แถบเครื่องมือ
- `●` หน้าชื่อ = ยังไม่ได้บันทึก, `×` = ปิดเอกสาร (ถามก่อนถ้ายังไม่บันทึก), `+` = เอกสารใหม่
- **ปิดเบราว์เซอร์แล้วเปิดใหม่ เอกสารที่เปิดค้างไว้จะกลับมาเหมือนเดิม** รวมถึงข้อความที่ยังไม่ได้บันทึก

### ค้นหาและแทนที่
- `Ctrl+F` ค้นหา, `Ctrl+H` ค้นหาและแทนที่
- `Enter` / `Shift+Enter` = ไปรายการถัดไป / ก่อนหน้า, `Esc` = ปิด
- **Aa** = ตรงตัวพิมพ์เล็ก-ใหญ่, **.\*** = ใช้ Regular expression
- ในโหมด regex ใช้ `$1`, `$2` ในช่องแทนที่ได้ เช่น ค้น `(\d{4})-(\d{2})-(\d{2})` แทนด้วย `$3/$2/$1` เปลี่ยน `2026-11-17` เป็น `17/11/2026`
- **แทนที่** ทีละรายการทำได้เฉพาะในมุมมอง source ส่วน **แทนที่ทั้งหมด** ใช้ได้ทุกมุมมอง

### ไฟล์บนดิสก์ถูกย้ายหรือลบ
ข้อความในแอปจะ **ไม่หาย** แค่ขึ้นป้ายสีเหลือง "ไม่พบไฟล์บนดิสก์" ให้ใช้ **บันทึกเป็น…** เพื่อเก็บเป็นไฟล์ใหม่

### Export
ผ่าน Command palette (`Ctrl+K`):
- **Markdown: ส่งออกเป็น HTML** — ดาวน์โหลดเป็นไฟล์ `.html`
- **Markdown: คัดลอกเป็น HTML** — วางลงอีเมล / Confluence / Word แล้วรูปแบบยังอยู่
- **Markdown: พิมพ์ / บันทึกเป็น PDF**

แถบล่างสุดแสดงจำนวนคำ ตัวอักษร และเวลาอ่านโดยประมาณ (นับคำภาษาไทยได้ถูกต้อง)

## 4. แท็บ JSON Path

ซ้าย = ช่องใส่ JSON, ขวา = tree และ path ของค่าที่เลือก

### ใส่ JSON
- วาง JSON ลงช่องซ้าย หรือเปิด / ลากไฟล์มา
- ใต้ช่องจะบอกว่า **JSON ถูกต้อง** หรือ **JSON ไม่ถูกต้อง** พร้อมบรรทัดและคอลัมน์ที่ผิด กด **ไปที่จุดผิดพลาด** เพื่อเลื่อนไปตำแหน่งนั้น
- **จัดรูปแบบ** = จัดย่อหน้าให้อ่านง่าย, **บีบอัด** = รวมเป็นบรรทัดเดียว

### หา path ของค่า
1. คลิกค่าใน tree ด้านขวา **หรือ** คลิกในข้อความ JSON ด้านซ้ายตรงค่าที่ต้องการ
2. กล่องด้านบนแสดง path 3 แบบ:

| แบบ | ตัวอย่าง | ใช้กับ |
| --- | -------- | ------ |
| JSONPath | `$.users[0].email` | Postman, REST Assured, JSONPath ทั่วไป |
| JavaScript | `data.users[0].email` | โค้ด JS / TS, Playwright |
| Lodash | `users[0].email` | `_.get()` |

3. กดปุ่ม 📋 ข้าง path หรือ **ดับเบิลคลิกที่ path** เพื่อคัดลอก
4. **คัดลอกค่า** = คัดลอกค่าที่เลือก (object / array จะได้ JSON ที่จัดรูปแล้ว)

### ใช้ tree ด้วยคีย์บอร์ด
`↑` `↓` เลื่อน, `→` ขยาย, `←` ยุบ, `Enter` / `Space` เลือก
ปรับความลึกเริ่มต้นได้ที่ตัวเลือก **ยุบทั้งหมด / ลึก 1–3 ชั้น / ขยายทั้งหมด**

### ค้นหา
พิมพ์ในช่องค้นหาด้านขวา:
- **ข้อความทั่วไป**: ค้นใน คีย์ + ค่า / คีย์ / ค่า (เลือกได้) ติ๊ก `.*` เพื่อใช้ regex
- **ขึ้นต้นด้วย `$`** = รัน JSONPath expression

| ตัวอย่าง | ได้อะไร |
| -------- | ------- |
| `$.users[*].name` | ชื่อของ user ทุกคน |
| `$..id` | ทุก `id` ในทุกระดับ |
| `$.items[0,2]` | รายการที่ 0 และ 2 |
| `$.items[1:3]` | รายการที่ 1 ถึง 2 |
| `$.items[-1]` | รายการสุดท้าย |

ยังไม่รองรับ filter แบบ `$..[?(@.price > 10)]`

### แปลงไฟล์อื่นเป็น JSON
เปิดไฟล์ `.csv` `.yaml` `.yml` `.jsonl` แอปจะแปลงเป็น JSON ให้ หรือวางข้อความแล้วเลือกจาก **แปลงจาก…**
- CSV: แถวแรกเป็นหัวคอลัมน์ ตรวจตัวคั่น `,` `;` tab อัตโนมัติ
- ไฟล์ที่แปลงแล้วเป็น **เอกสาร JSON ใหม่** กดบันทึกจะไม่ทับไฟล์ต้นฉบับ

## 5. แท็บ Locator

ใช้หา locator สำหรับเขียน test automation โดยไม่ต้องเปิด DevTools

### ขั้นตอน
1. ไปที่หน้าเว็บที่ต้องการ กด `Ctrl+U` (ดู source) หรือคลิกขวา → *View page source* แล้วคัดลอกทั้งหมด
   (หรือใน DevTools คลิกขวาที่ `<html>` → *Copy* → *Copy outerHTML* ซึ่งได้ HTML ที่ JavaScript สร้างแล้วด้วย)
2. วางลงช่องซ้าย หรือเปิดไฟล์ `.html`
3. **คลิก element ในหน้าตัวอย่างด้านขวา** หรือคลิกที่ tag / ข้อความในช่อง source ด้านซ้าย
4. เลือกรูปแบบที่ **Locator สำหรับ** แล้วกด 📋 หรือดับเบิลคลิกที่โค้ดเพื่อคัดลอก

### รูปแบบที่รองรับ

| ตัวเลือก | ตัวอย่างผลลัพธ์ |
| -------- | --------------- |
| Playwright | `page.getByRole('button', { name: 'Sign in' })` |
| Robot Framework | `id:login-btn`, `css:...`, `xpath:...` |
| Cucumber Java (Selenium) | `driver.findElement(By.id("login-btn"))` |
| Playwright Java | `page.getByRole(AriaRole.BUTTON, new Page.GetByRoleOptions().setName("Sign in"))` |

ลิงก์ **Docs** ข้างตัวเลือกจะเปิดเอกสาร locator ทางการของเครื่องมือนั้น

### อ่านผลลัพธ์
- locator เรียงจาก **แนะนำที่สุด** ลงไป: test id → role → label → placeholder → text → … → CSS → XPath
- ป้ายด้านขวาของแต่ละ locator:
  - **ไม่ซ้ำ / unique** (สีเขียว) = ชี้ element เดียว ใช้ได้เลย
  - **ตรง N ตัว** = ชี้หลาย element ต้องทำให้เจาะจงขึ้น
- ถ้า locator ของ element ที่เลือกยังไม่ดีพอ กด **ตัวแม่ / Parent** เพื่อขยับไปที่ element ครอบ

> ⚠️ หน้าตัวอย่าง **ไม่รัน JavaScript และไม่โหลด CSS / รูปจากภายนอก** (เพื่อความปลอดภัย)
> หน้าตาจึงอาจไม่เหมือนเว็บจริง และ element ที่สร้างตอนรันจะไม่มี — **ตรวจ locator กับหน้าจริงอีกครั้งเสมอ**

### แท็บ PDF

เปิดไฟล์ `.pdf` ด้วยปุ่ม Open หรือลากมาวาง (หรือกด `Alt+6` เพื่อไปที่แท็บ)

- **เครื่องมือ**: เลือก / ย้าย, เพิ่มข้อความ, ไฮไลต์, กรอบ, ปิดทับ, ปากกา
- **หน้าเอกสาร**: หมุน ลบ ย้าย ทำสำเนา แทรกจาก PDF อื่น
- **บันทึก / ส่งออก**: `Ctrl+S` บันทึกเป็น PDF หรือกด Export เพื่อเลือก PDF, PNG, JPEG, `.txt`, `.md`
- **คีย์ลัด**: `Alt+Z` ย้อนกลับ, `Alt+Shift+Z` ทำซ้ำ, `Alt+↑` / `Alt+↓` เปลี่ยนหน้า

> ⚠️ **ปิดทับ** ซ่อนเฉพาะที่มองเห็น ข้อความเดิมยังอยู่ในไฟล์ ห้ามใช้ลบข้อมูลลับ

## 6. Command palette (`Ctrl+K`)

ทุกคำสั่งในแอปอยู่ที่นี่ พิมพ์บางส่วนของชื่อคำสั่งแล้วกด `Enter`

ตัวอย่างคำสั่งที่มีเฉพาะใน palette:
- Markdown: ส่งออกเป็น HTML / คัดลอกเป็น HTML / พิมพ์ / บันทึกเป็น PDF
- Markdown: รีเซ็ตการแบ่ง source/preview
- JSON: แปลงข้อความจาก CSV / YAML / JSON Lines
- Locator: แสดงแบบ Playwright / Robot Framework / …
- ช่วยเหลือ: บันทึกการเปลี่ยนแปลง

`↑` `↓` เลื่อน, `Enter` รัน, `Esc` ปิด
ชื่อคำสั่งจะเป็นภาษาเดียวกับ UI ที่เลือกอยู่

## 7. ภาษา ธีม และโหมดซ่อน UI

- **ภาษา**: ปุ่ม **文A EN / TH** สลับ English ↔ ไทย ได้ทันที งานที่ทำค้างไม่หาย
  ครั้งแรกจะเลือกตามภาษาของเบราว์เซอร์ และจำค่าที่เลือกไว้
- **ธีม**: กดวน อัตโนมัติ (ตามระบบ) → สว่าง → มืด
- **ซ่อน UI** (`Ctrl+.` หรือปุ่ม ⛶): ซ่อนแถบเครื่องมือทั้งหมด เหลือแต่เนื้อหา เหมาะกับการอ่านหรือแชร์หน้าจอ
  กลับด้วย `Esc`, `Ctrl+.` หรือปุ่มจาง ๆ มุมขวาบน

## 9. ข้อจำกัดและคำถามที่พบบ่อย

**ใช้ออฟไลน์ได้ไหม?**
ได้ หลังเปิดเว็บครั้งแรก ติดตั้งเป็นแอปได้จากปุ่มติดตั้งในแถบที่อยู่ของ Chrome / Edge

**ข้อมูลของฉันถูกส่งไปไหนไหม?**
ไม่ ทุกอย่างทำงานในเบราว์เซอร์ เอกสารที่เปิดค้างเก็บในเครื่องคุณเท่านั้น

**ปิดแท็บไปแล้ว งานที่ยังไม่บันทึกหายไหม?**
- Markdown: ไม่หาย เปิดกลับมาจะยังอยู่
- JSON Path / Locator: **หาย** แอปจะเตือนก่อนปิดหน้าถ้ามีงานค้าง

**แก้ใน Read & edit แล้วบันทึก ทำไม Markdown เปลี่ยนนิดหน่อย?**
editor จัดรูปแบบ Markdown ใหม่ตอนบันทึก (เช่น สัญลักษณ์ bullet) เนื้อหาไม่เปลี่ยน

**เว็บยังเป็นเวอร์ชันเก่า?**
กด `Ctrl+Shift+R` (`Cmd+Shift+R`) หรือปิดแท็บแล้วเปิดใหม่ ดูเวอร์ชันได้ที่มุมซ้ายบน

**ลองฟีเจอร์ได้จากไหน?**
แต่ละแท็บมีตัวอย่างโหลดไว้ให้ตอนเปิดครั้งแรก และมีไฟล์ตัวอย่างเพิ่มในโฟลเดอร์ [examples/](../examples/)
