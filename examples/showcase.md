# QAReadar

ตัวอย่างสั้นๆ สำหรับลองแท็บ **Markdown** — กด `Ctrl+K` เพื่อค้นหาคำสั่งทั้งหมด

## ลองดู

- [x] เปิดไฟล์นี้
- [ ] **Outline**: คลิกหัวข้อเพื่อกระโดดไป
- [ ] **Read & edit**: พิมพ์แก้ในหน้าอ่านได้เลย
- [ ] `Ctrl+F` ค้นหา `TODO` · `Ctrl+H` แทนที่เป็น `DONE`
- [ ] `Ctrl+K` → **Export as HTML**

## ตัวอย่างเนื้อหา

ตัวหนา **bold**, ตัวเอียง *italic*, ~~ขีดฆ่า~~, `code` และ [ลิงก์](https://developer.mozilla.org)

| ฟีเจอร์ | คีย์ลัด |
| ------- | ------- |
| ค้นหา | `Ctrl+F` |
| แทนที่ | `Ctrl+H` |

# บรรทัดนี้อยู่ใน code block จึงไม่นับเป็นหัวข้อ
